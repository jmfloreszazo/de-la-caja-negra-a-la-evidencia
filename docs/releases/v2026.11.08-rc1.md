## Evidence custody

Historical evidence ZIPs were relocated without recompression or byte changes
to local `evidence/archives/preserved-dist/`. The relocation inventory and archive
manifest are versioned; the private payloads are **not included in the Git repository
or automatically uploaded as release assets**. A public clone therefore does not
contain all original raw campaign archives. Arrange authorized delivery separately.
Historical receipts and original failed attempts remain unchanged.

Two legacy receipts do not contain an archive digest. The archive inventory can
be consistent while receipt verification remains `INCOMPLETE`; this is not waived.
No new Azure run is implied by publication or by rebuilding the PDFs.

## Acceptance limits

- E3: one VM and synthetic offered rates; no approved bank capacity contract,
  physical-node HA, on-premises/mainframe comparison or full TCO.
- E4: one original model invocation and recorded-response replay, not a comparative
  population study; human-review time and invoiced cost remain unmeasured.
- TODM: bounded technical verdicts do not establish trusted G2/G6 approval.
  Methodology remains `INCONCLUSIVE`, production release authorization `BLOCK`.
- Decision/process tools implement limited JSON profiles, not full DMN/FEEL,
  BPMN XML, CMMN, SBVR or OCL engines.
- Publication candidates must show the actual CI outcomes; configured workflows
  and local test results alone are not evidence that remote pipelines passed.
